## Ringkasan Materi
 
Pertemuan pertama membahas pengenalan **Visual Programming**, mulai dari karakteristik, tujuan dan manfaat, keterbatasan, hingga contoh bahasa pemrograman dan platform yang digunakan dalam pendekatan visual programming.
 
---
 
## 1. Karakteristik Visual Programming
 
- Logika program direpresentasikan melalui blok, diagram, atau elemen grafis yang saling terhubung sesuai dengan alur program.
- Komponen program maupun antarmuka dapat disusun melalui mekanisme *drag-and-drop*, sehingga proses perancangan menjadi lebih intuitif.
- Perubahan pada rancangan atau struktur program dapat diamati secara langsung, sehingga memudahkan proses evaluasi dan pengembangan.
## 2. Tujuan dan Manfaat Visual Programming
 
- Mempermudah pemahaman konsep dasar pemrograman.
- Menyajikan alur program secara visual dan terstruktur.
- Mempersiapkan pengguna sebelum mempelajari sintaks kode.
- Meminimalkan kesalahan dalam penulisan kode.
## 3. Keterbatasan Visual Programming
 
- **Fleksibilitas Terbatas**
- **Kurang Efisien untuk Proyek Besar**
- **Ketergantungan pada Platform**
## 4. Visual Basic
 
Visual Basic merupakan bahasa pemrograman dari Microsoft yang menyediakan lingkungan pengembangan terintegrasi (IDE) untuk membangun aplikasi dengan pendekatan visual.
 
## 5. Platform Visual Programming
 
Beberapa platform yang digunakan dalam pembelajaran maupun pengembangan visual programming, antara lain:
 
- **Scratch** — platform berbasis blok yang digunakan untuk memperkenalkan konsep dasar pemrograman melalui pemrograman visual yang sederhana dan interaktif.
- **MIT App Inventor** — platform berbasis blok untuk membangun aplikasi mobile (Android) secara visual.
- **Visual Basic** — IDE dari Microsoft yang mendukung pengembangan aplikasi dengan pendekatan visual (desain form dan komponen antarmuka).
- **JavaFX** — framework untuk membangun antarmuka aplikasi desktop berbasis Java, dilengkapi dengan Scene Builder untuk mendesain antarmuka secara visual.
---
 
## Kesimpulan
 
Visual Programming merupakan pendekatan pemrograman yang menyajikan logika program secara visual melalui blok dan elemen grafis, sehingga memudahkan pemula dalam memahami konsep dasar pemrograman sebelum mempelajari sintaks kode secara langsung. Meskipun memiliki keterbatasan dalam hal fleksibilitas dan efisiensi untuk proyek besar, visual programming tetap menjadi metode yang efektif sebagai langkah awal pembelajaran pemrograman.
